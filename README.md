Stochastic Character Mapping and Branch-Model Analysis with codeml (PAML)

This repository contains the scripts used to perform stochastic character mapping and branch-model analyses using codeml (PAML).
The workflow is general and can be applied to any gene family or phylogeny. These scripts were used for the analyses in the associated manuscript.

scripts:   
trim_full_scm_to_gene_subset.R  —  trim trait tree for specific gene subset  
scm_and_trim.R  — 2 modes (stochastic character mapping or trimming)  
run_branch_models_subset_parallel.sh  — run codeml branch-model in parallel
